# 요구사항 정의서 v2

> 원본: Notion「요구사항 정의서 v2」(2026-09-05 기준, 해커톤 MVP)
> 서비스는 외화·해외자산 AI 가이드이며, 앱 이름 미확정으로 문서에서는 `서비스`로 표기한다.

## 1. 제품 정의

환율의 정답을 맞히거나 특정 상품을 대신 선택하는 서비스가 **아니다.** 환율 범위·변동성·개인 외화 노출을 이해하기 쉽게 설명하고, 사용자가 자신의 조건에 맞는 행동 경로를 준비하도록 돕는 AI 금융 가이드다.

**핵심 사용자**: 금융 전문가가 아닌 일반 소비자, 해외주식·ETF·외화 보유자, 반복 매수/여행·학비 등 특정 시점 외화가 필요한 사용자.

### v2 핵심 변경
- 랜딩 온보딩이 아니라 **로그인 이후 초기 설정**에서 정보를 받는다.
- `오늘 무엇을 하시겠어요?` 목적 선택으로 앱/홈을 분기하지 않는다.
- 간편 진단(Q1~Q3)과 상세 진단(Q4~Q6)을 분리한다.
- 대표 위험성향은 **Q1~Q3만으로** 계산한다.
- Q5는 금융 이해도(A~D) 대신 **설명 선호 3단계**로 교체.
- 직업 입력은 선택형 `익숙한 설명 분야`로 대체.
- 메뉴·카드 순서는 고정, **설명·제시값·도움말·경고만 개인화**한다.
- AI는 계산하지 않고 검증된 결과를 설명만 한다.

## 2. 예측 정보의 구분

| 구분 | 표시 | 행동 계산 사용 |
|---|---|---|
| 예상 변동폭·예측 범위 | 제공 | Route 설계 후 확정 |
| 방향 참고 경로·전망 동인 | 참고 정보로 제공 가능 | **사용 금지** |
| `지금 사라/팔라` 지시 | **제공 금지** | 사용 금지 |

Forecast 중앙선 주변 음영은 변동성 자체가 아니라 **예측 범위·불확실성 구간**이다.

### 하지 않는 것
환율 방향/가격 도달 보장, 방향 전망 기반 환전·매수 시점 결정, 특정 종목·통화 매수·매도 단정, 실제 환전·주문 실행, AI의 임의 수치 생성, 급변장에서 최신 정보 은폐 — 모두 하지 않는다.

## 3. 주요 용어

| 용어 | 정의 |
|---|---|
| 대표 위험성향 | Q1~Q3으로 계산한 안정/균형/적극/도전 항로 유형 |
| 외화 비중 | 총자산 중 외화자산 비율 |
| 통화 노출 | 외화자산 내 USD·JPY·EUR 등의 비중 |
| 환율 민감도 | 환율 1% 변동 시 원화 평가금액 변화량 |
| 예측 범위 | 정해진 기간 내 환율이 포함될 상·하단 구간 |
| 스트레스 테스트 | 주가·환율 충격 가정을 적용한 조건부 자산 계산 |
| 급변 상태 | 시장 충격·데이터 이상으로 전망 불확실성이 커진 상태 |
| RouteContext | 진단·전망·자산·스트레스 결과를 Route에 전달하는 데이터 계약 |

## 4. 기능 요구사항 (모듈별 요약)

우선순위 — **M**: MVP 필수, **S**: 여유 시, **P**: 구조만 준비, **W**: MVP 제외

### 4.1 공통 (FR-CM)
기준일 표시, Mock은 `시연용 예시 데이터` 명시, 면책 고정 표시, 외화의 원화 병기, `USD/KRW 상승=원화 약세` 해석 전 화면 통일, 설명 선호 3단계(`핵심만 쉽게 / 숫자와 이유 / 지표와 한계`), **UI 순서 고정**(문구·제시값·도움말·경고 강도만 개인화), 빈 상태 전용 처리, 데이터 출처 표시, 반응형(S).

### 4.2 인증·초기 설정 (FR-IS)
로그인 후 최초 사용자만 초기 설정 진입. 간편 진단·설명 분야·자산 상태(Mock/없음)를 시작하거나 **모두 건너뛰어도** 홈 이용 가능. 건너뛴 항목을 임의 기본 성향으로 저장하지 않음. 재방문 시 초기 설정 반복 안 함. 여행/투자 분기 질문 제거.

### 4.3 위험성향 진단 (FR-DG)

**Q1~Q3 간편 진단** — 손실 수용도 / 수익·안정 선호 / 자산 변동 편안함. 선택 A=0·B=1·C=2·D=3 점수 합산:

| 합계 | 대표 유형 |
|---|---|
| 0~2 | 안정항로형 |
| 3~4 | 균형항로형 |
| 5~6 | 적극항로형 |
| 7~9 | 도전항로형 |

**Q4~Q6 상세 진단** — Q4 생활자금 분리(제목 수식어·경고에만 사용, 점수 불변), Q5 설명 선호 방식, Q6 보유 경험(도움말 강도). Q4~Q6은 **대표 유형 점수를 바꾸지 않는다.**

동작: Q1~Q3 전부 응답해야 유형 계산, 하나라도 미응답이면 `미측정`, 상세는 Q4부터 시작, 중단 시 응답 저장 후 재개, 혼합 응답은 새 유형 대신 보조 설명, `왜 이렇게 나왔나요?` 근거 제공, MVP 가설 한계 표시.

### 4.4 홈 (FR-HM)
오늘의 핵심 요약 우선 노출, 위험성향·Fit 관계, 외화 현황(비중·통화별 노출·전일 대비·1% 민감도), 목표 영역, 주의 필요(급변·임박 일정), Forecast 요약(S). **카드 순서 고정**, 프로필·설정은 우측 상단 프로필로 분리.

### 4.5 Forecast (FR-FC)
USD·JPY·EUR Mock 전환, 30일 기본, 팬 차트(과거 실선·오늘 기준선·미래 중앙 참고 경로·예측 범위), 음영은 `예측 범위/불확실성 구간`으로 라벨, 변동성 점수/백분위 별도 표시, 환율 1% 자산 영향, 기본 4문장 요약, 맞춤 표현은 표현에만 반영(숫자·근거 불변), 모델 가정·오차·한계 펼침. **방향 전망을 Route 계산 입력으로 전달 금지.**

### 4.6 X-Ray (FR-XR)
외화 비중·금액, 통화별 노출, 집중도(최대 노출·기준선 초과), 손익 분해(자산가격·환율·상호작용·비용), 환율 1% 민감도(통화별·합계), 종목 상세(S), Mock 자산 편집. 실제 계좌 연동(W).

원화 수익률 검증식:
```
R_KRW = (1 + R_asset) × (1 + R_fx) - 1
      = R_asset + R_fx + R_asset × R_fx
```

### 4.7 Fit (FR-FT)
대표 위험성향과 현재 외화 노출의 관계 설명, 집중도·성향별 참고 기준선, 변화 미리보기(S), 절대적 적합/부적합·상품 추천 표현 금지, 진단 결과를 RouteContext로 전달(P). 통화별 투자 순위·기대수익 추천 금지(W).

### 4.8 Stress Test (FR-ST)
기본 시나리오(주가 하락+원화 약세 / 주가 하락+원화 강세), 실제 사건 참고(S), 주가·환율·총 평가금액 효과 분리, 결과는 예측이 아닌 가정 충격의 계산임을 표시, 충격값·기준일·가정 공개, RouteContext 저장(P).

### 4.9 AI 설명 (FR-AI)
점수·금액·범위·등급은 **규칙 기반 계산 엔진**이 생성, AI는 검증된 JSON 값만 설명에 사용, 설명 선호·익숙한 분야로 어휘·비유·밀도만 조정, Forecast 요약 기본 4문장, 후처리로 숫자·통화·기간·방향 일치 검사, 실패 시 고정 템플릿 폴백, 보장·확정·`반드시 매수` 등 표현 차단, 챗봇은 보조 창구.

### 4.10 마이페이지 (FR-MY)
우측 상단 프로필 진입, 계정 정보, 대표 유형·진단일·근거, 진단 상태(미측정/간편/상세), 설명 선호 변경, 익숙한 분야 변경, 자산 상태 바로가기. MVP는 최신 결과·진단일만 저장(전체 이력은 확장, S).

### 4.11 급변 상태 (FR-SF)
급변 시에도 최신 정보·충격 사실 은폐 금지, 평시/주의/급변 상태 구분, 범위·오차 확대 설명, 계획 기준일·가정 확인(P), 재계산/유지 사용자 선택(P), 데이터 오류와 실제 충격 구분(S).

### 4.12 Route 연결 (FR-RT) — 구조만 준비(P)
RouteContext 정의, 투자+기한형 외화 목표 병행, 비강제 샘플 체험, 예측 비의존 기본 경로, `상황→선택→비교→계획→재검토` 흐름, 변경 기록. 실제 환전·주문 안 함(W).

> **Route 미확정 값**: 목적함수, 최소 입력값, 안전·기회 버킷 존재/비율, 목적별 하한선, 권장 분할 회차, 몬테카를로 적용 여부, 달성 확률 정의, 화면 형태. 기존 문서의 50/70/85/95% 비율과 4~8회 권장값은 **후보일 뿐 확정 요구사항 아님**.

## 5. 비기능 요구사항 (요약)

- **성능(S)**: 첫 주요 화면 3초 이내 목표.
- **접근성(M)**: WCAG AA 대비, 색만으로 상승·하락·위험 구분 금지, 키보드 포커스·접근성 이름 제공.
- **UI(M)**: 카드·메뉴 순서 고정, 넓은 표·차트는 자체 컨테이너 스크롤.
- **데이터(M)**: 모든 수치에 기준일·데이터 상태, 동일 수치는 한 Mock fixture에서 공급, 데모/실제 구분.
- **AI(M)**: 생성형 AI는 산술 계산·최종 판정 금지, 출력 수치를 엔진 결과와 대조해 불일치 시 폐기, AI 실패가 핵심 계산·화면 이용을 막지 않음.
- **보안(M)**: 비밀번호 평문 저장 금지, 자산·진단 데이터 소유자 단위 분리.
- **규제(M)**: 투자 권유·수익 보장처럼 표현 금지.

## 6. MVP 범위 요약

| 구분 | 내용 |
|---|---|
| **Must** | 인증 Mock, 로그인 후 초기 설정, 간편·상세 진단, 결과 근거, 홈, Forecast, X-Ray, Fit, Stress Test, 마이페이지, AI 폴백 |
| **Should** | 실제 AI API 연결, 역사 시나리오, 반응형, 접근성 보완, 설명 근거 아코디언 |
| **Prepare** | RouteContext, Route 연결 CTA, 목표 빈 상태, 급변장 계획 재검토 연결 |
| **Won't** | 실제 마이데이터, 실제 환전·주문, 자동매매, 신흥국 통화, AML 본 구현, 유료 구독 |

## 7. 미결정 항목
최종 앱 이름/Route 노출 명칭, 메인 강조색 2종, 위험성향 점수 체계 검증, 재진단 주기·이력, Forecast 실제 모델·데이터 소스·갱신 주기, Fit 기준선 산출 근거, Route UX·계산 로직 전체.
