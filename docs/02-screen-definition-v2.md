# 화면 정의서 v2

> 원본: Notion「화면 정의서 v2」(2026-09-05 기준, 해커톤 프론트 MVP)
> 원칙: 화면 구조는 고정하고 **설명과 제시값만 개인화**한다. Route 상세 화면은 제외.

## 1. 화면 지도

```
랜딩 → 로그인·회원가입 → 로그인 후 초기 설정 → 간편·상세 진단 → 한눈에 보기
                                    └(건너뛰기)────────────────┘
한눈에 보기 → 환율 전망 / X-Ray / Fit / Stress Test / Route 연결 / 마이페이지
```

| 화면 | 역할 | MVP |
|---|---|---|
| 랜딩 | 서비스 가치·한계 설명 | 구현 |
| 로그인·회원가입 | 인증·샘플 체험 진입 | Mock 가능 |
| 초기 설정 | 로그인 후 최소 개인화 | 구현 |
| 진단 | 간편 Q1~Q3, 상세 Q4~Q6 | 구현 |
| 한눈에 보기 | 위험성향·외화 현황·주의·시장 요약 | 구현 |
| 환율 전망 | 예상 범위·변동성·개인 영향 | 구현 |
| X-Ray | 통화 노출·손익·민감도 | 구현 |
| Fit | 성향과 외화 노출 관계 | 구현 |
| Stress Test | 급변 시나리오별 자산 영향 | 구현 |
| Route | 행동 계획 가이드 | **연결 화면만 준비** |
| 마이페이지 | 계정·진단·설명·자산 상태 | 구현 |

목적에 따라 별도 앱/홈으로 보내지 않는다. 모든 사용자가 같은 메뉴 구조를 쓴다.

## 2. 공통 셸

- **데스크톱**: 좌측 고정 사이드바 / 상단(기준일·데모 배지·상태 배지·우측 프로필) / 본문(제목·핵심 설명·고정 순서 콘텐츠) / 보조 영역 AI 질문 / 하단 면책·데이터 상태.
- **모바일**: 상단 로고·상태 배지·프로필 / 하단 내비게이션 / 차트·표는 카드 내부에서만 가로 스크롤.
- **고정 내비게이션**: ① 한눈에 보기 ② 환율 전망 ③ X-Ray ④ Fit ⑤ Stress Test ⑥ Route. 마이페이지는 메뉴 카드가 아니라 우측 상단 프로필 아이콘.

**공통 표시 요소**: 기준일, 데모 배지(`시연용 예시 데이터`), 상태 배지(정상/주의/급변), 데이터 없음(0 차트 아닌 전용 빈 상태), 면책, AI 버튼(주 조작수단 아님).

### 개인화 범위
- **가능**: Forecast 4문장, 카드 내부 확인 순서, 기본 입력 제시값, 도움말 노출 강도, 급변·집중도 경고 문구, 익숙한 분야 비유.
- **금지**: 사이드바 순서, 홈 카드 순서, 실제 시장 데이터, 위험성향 점수, 예측 범위·자산 금액, 계산 결과.

## 4. 랜딩
비로그인 사용자에게 서비스가 무엇을 해주고 무엇을 안 하는지 이해시킨다. 구성: 히어로(범위·자산 영향 이해 가치) → 핵심 기능(Forecast·X-Ray·Fit·Stress Test·Route) → 작동 방식(시장 범위→내 자산 영향→계획 연결) → 상세 개인화 안내 → 하지 않는 것(수익 보장·특정 통화 추천·자동 실행 없음) → CTA(로그인·회원가입, 선택적 데모).

**변경**: 랜딩에서 개인정보·위험성향·목적을 묻지 않는다.

## 5. 로그인·회원가입
이메일·비밀번호·로그인·회원가입·비밀번호 찾기·선택적 샘플 둘러보기.
- 첫 로그인 → 초기 설정
- 완료 사용자 → 한눈에 보기
- 샘플 체험 → 데모 배지 유지한 채 한눈에 보기

## 6. 로그인 후 초기 설정
로그인 후 한 번 나타나는 개인화 단계. **모든 단계 건너뛰기 가능.**

| 단계 | 화면 | 처리 |
|---|---|---|
| 1 | 간편 진단 제안 | Q1~Q3 시작 또는 `나중에 할게요` |
| 2 | 익숙한 설명 분야 | 선택 또는 건너뛰기 |
| 3 | 자산 시작 방식 | Mock 자산 체험 또는 빈 상태 |
| 4 | 완료 | 한눈에 보기로 이동 |

**UX 원칙**: 목적·직업·수입·지출 강제 입력 금지, 건너뛴 값 임의 채움 금지, 상세 진단은 결과 화면/마이페이지에서 선택, 추가 입력 시 무엇이 달라지는지 먼저 설명.

## 7. 간편 진단 Q1~Q3
상단 `3개 중 N번째` 진행 표시, 중앙 핵심 질문, 보조문구, A~D 선택지, 하단 이전/다음. 판정은 A=0·B=1·C=2·D=3 합산(0~2 안정 / 3~4 균형 / 5~6 적극 / 7~9 도전).

**예외**: 하나라도 미응답이면 결과 미계산, 중단 시 답변 저장, 재진입 시 미응답 질문부터.

## 8. 간편 결과
대표 유형 → 응답 조합 2~3문장 설명 → `왜 이렇게 나왔나요?` 아코디언 → `3개 질문으로 더 자세히 보기` → `한눈에 보기로 이동`.

혼합 응답(예: `A-D-A`=3점=균형항로형)은 새 유형을 만들지 않고 보조 설명으로 처리하며, MVP 가설임을 표시한다.

## 9. 상세 진단 Q4~Q6
간편 결과 유지, Q4부터 시작.

| 문항 | 판단 대상 | UI 영향 |
|---|---|---|
| Q4 | 생활자금과 외화·투자자금 분리 | 결과 제목 수식어·자금 경고 |
| Q5 | 원하는 설명 방식 | 설명 밀도 |
| Q6 | 실제 보유 경험 | 도움말·용어 풀이 강도 |

Q5 선택지: `핵심과 내 돈에 미치는 영향만 쉽게` / `숫자와 이유까지 함께` / `지표와 모델의 한계까지 자세히`. A·B·C 내부 코드는 노출 금지.

**유도 UX**: 간편 결과 아래 상세 진단 이점을 미리 보여주는 바텀시트(배경 약하게 흐림, `더 자세히 보기`+`이대로 시작하기`, 미실시해도 기능 제한 없음).

## 10. 상세 결과
제목: `Q4 수식어 + 대표 유형`(예: "지출 균형을 함께 고려하는 균형항로형"). 구성: 제목 → Q1~Q3 패턴 설명 → Q4 자금 상태 포함 3~5문장 → 적용 설명 방식 한 문장 → 문항별 근거 아코디언 → 한눈에 보기 이동. 딱딱한 결과 카드 반복 금지.

## 11. 한눈에 보기
**오늘 알아야 할 개인 금융 상태**를 보여준다(시장 브리핑/마이페이지 아님).

| 순서 | 블록 | 구성 | 빈 상태 |
|---|---|---|---|
| 1 | 오늘의 핵심 | 중요 변화·주의·한 줄 가이드 | 일반 안내 |
| 2 | 위험성향·Fit 요약 | 대표 유형·현재 노출 관계 | 진단하기 CTA |
| 3 | 내 외화 현황 | 외화 비중·통화 노출·1% 민감도 | 자산 체험/등록 CTA |
| 4 | 목표·Route | 진행 중 목표 요약 | Route 준비/목표 빈 상태 |
| 5 | 주의 필요 | 급변 상태·임박 일정 | `특이사항 없습니다` |
| 6 | 환율 전망 요약 | 현재값·예상 범위·미니차트 | 데이터 없음 |

**고정 규칙**: 위험성향에 따라 카드 순서 변경 금지, 마이페이지 항목 반복 금지, 통화 선택 탭은 Forecast에 둔다.

## 12. 환율 전망
페이지 메시지: "환율을 하나의 숫자가 아니라 범위와 불확실성으로 봅니다."

구성: 선택자(USD·JPY·EUR·기간·기준일) → 팬 차트 → 핵심 3지표(예상 범위·변동성·내 자산 영향) → 맞춤 4문장(현재 상황·범위·개인 영향·주의점) → 주요 근거 → 일정 → 모델 정보 아코디언 → Route 연결.

**팬 차트 라벨**: 과거 실선(실제 관측값), 중앙선(모델 참고 중심 경로), 음영(50%·80% 예측 범위), 변동성(별도 점수/백분위). 음영을 `변동성`이라 부르지 않는다.

**설명 선호별 4문장**: 핵심만 쉽게(결론·내 돈 영향·주의·읽는 법) / 숫자와 이유(현재값·범위·변동성·개인 손익) / 지표와 한계(구간 수준·변동성 지표·민감도·모델 한계). 세 출력은 **같은 사실·숫자**를 사용한다.

## 13. X-Ray
페이지 메시지: "수익 중 자산 가격과 환율이 만든 부분을 나누어 봅니다."

구성: 외화 비중 → 통화별 노출 스택바 → 손익 분해(자산가격·환율·상호작용·비용) → 환율 민감도(1% 변동, 통화별·합계) → 종목별 상세 → 자산 편집(Mock 추가·수정·삭제).

빈 상태: `아직 등록된 해외자산이 없습니다.` + `샘플 자산으로 보기` / `직접 입력하기`. 샘플 선택 시 데모 배지 유지.

## 14. Fit
페이지 메시지: "내 성향과 지금의 외화 노출이 같은 방향을 보고 있는지 확인합니다."

구성: 대표 위험성향(유형·진단일·미측정) → 현재 집중도(주력 통화·비중·기준선) → 관계 설명 → 변화 미리보기(비중 변화 시 집중도·민감도) → Route 연결 → 판단 기준(절대 추천 아닌 이유·한계).

**표현 금지**: `JPY가 가장 좋은 투자입니다` / `USD를 지금 팔아야 합니다` / `당신에게 적합한 종목입니다`. 대신 "이 선택을 추가하면 USD 집중도가 64%→60%로 낮아지는 가정입니다"처럼 변화값을 설명.

## 15. Stress Test
페이지 메시지: "실제로 일어날 수 있는 급변 상황을 가정해 내 자산이 어떻게 흔들리는지 봅니다."

기본 시나리오: 주가 하락+원화 약세 / 주가 하락+원화 강세 (사용자 정의는 여유 시). 구성: 시나리오 선택(이름·참고 사건·가정) → 충격값(주가·환율 변화율) → 결과(주가 효과·환율 효과·총 평가금액 변화) → 해석(환율이 손실 완충/확대) → Route 연결. 결과는 예측이 아닌 **입력 충격값에 대한 조건부 계산**임을 표시.

## 16. 마이페이지
우측 상단 프로필 아이콘 진입. 섹션: 프로필(이름·이메일·비밀번호) / 위험성향(유형·상태·진단일·근거) / 진단 관리(이어하기·상세·재진단) / 설명 설정(3단계) / 익숙한 분야 / 자산 상태(Mock·미등록·직접 입력 + X-Ray 바로가기) / 알림(급변·일정·계획 재검토). 자산·목표 상세 편집은 복제하지 않는다.

## 17. AI 추가 설명
위치: 우측 하단 플로팅 버튼 또는 근거 영역의 `쉽게 설명해줘`.
- **역할**: 계산된 결과의 재설명, 용어 설명, 시나리오 가정 설명, 익숙한 분야 비유.
- **하지 않는 역할**: 메뉴 전체 조작, 점수·환율·손익 재계산, 새 추천 비중 생성, 투자 실행 지시.
- AI 실패 시 카드·계산값 유지, 고정 설명 표시.

## 18. Route 연결 화면 — 현재 범위
Route는 와우 포인트이나 UX·계산 로직 동시 확정이 필요해 완성안으로 고정하지 않는다.
- **지금 구현**: 사이드바 Route 메뉴, 목표 없을 때 빈 상태, Forecast·Fit·Stress Test에서 RouteContext 전달, 준비 중 기능 플래그/제한 샘플, `투자`+`기한 있는 외화 목표` 병행 데이터 구조.
- **확정 UX 원칙**: 필름 카드 단순 나열 안 함, 입력 완료 전 샘플 체험 가능, `상황→선택→비교→계획→재검토` 흐름, Forecast 방향값 하나로 계획 결정 안 함, 실제 환전·주문 안 함.
- **확정값으로 넣지 않을 것**: 안전·기회 버킷 비율, 목적별 최소 안전 비율, 4~8회 권장 회차, 목표 달성 확률, 몬테카를로 횟수, Route 히어로 지표, 좌우 분할 레이아웃.

## 19. 화면 간 데이터 흐름

| 보내는 화면 | 받는 화면 | 데이터 |
|---|---|---|
| 진단 | 홈·Fit | 대표 유형·상세 수식어·설명 선호·경험 |
| 마이페이지 | 전 화면 | 설명 선호·익숙한 분야 |
| X-Ray | Forecast | 통화별 자산 금액·민감도 |
| Forecast | RouteContext | 범위·변동성·기준일 (**방향 전망 제외**) |
| X-Ray | RouteContext | 보유 외화·통화 노출·집중도 |
| Fit | RouteContext | 성향-노출 관계·가정 변화 |
| Stress Test | RouteContext | 충격값·자산 영향 |

## 20. 상태 정의
